# Antigravity Agent Operations Specification

## 1. Operating Boundaries
* **Context Access:** Reading and modifying assets within the consolidated local dashboard directories.
* **Credentials:** Utilize the native machine environment `GOOGLE_APPLICATION_CREDENTIALS` variable for Google Cloud BigQuery client authentication.
* **Execution Window:** The pre-calculation pipeline executes automatically after match blocks conclude, writing static payloads to disk.

## 2. Ingestion & Storage Architecture
To eliminate ongoing database interaction costs, data must be structured into flat JSON files:
* `/data/bracket/grid_state.json`: Holds Section 1 live bracket configurations and structural paths.
* `/data/standings/group_tables.json`: Stores points, goal differentials, and underlying metrics ($xG$, field tilt) for Section 2.
* `/data/matches/{match_id}/summary.json`: Ingests the NLP-purified tactical bullet narratives generated through Google AI Studio.
* `/data/matches/{match_id}/metrics.json`: Houses the pre-calculated team and player data frames generated by `fifa_metrics_bq.py`.

## 3. Tool Binding Protocol
The agent has permission to bind and execute functions from `fifa_metrics_bq.py` directly using a localized automation script (`compile_static_fixtures.py`).
